# kforjan's dotfiles

## How to use
------
Clone to home dir
```
cd .dotfiles
stow .
```
------
## Requirements:
Install alacritty
Install i3wm
Install rofi
Install tmux
 - Install tmux plugin manager
Install zsh
Install gnu stow
Instal OMZ
 - clone zsh-autosuggestions, zsh-syntax-highlighting, fzf-tab and zsh-completions to ~/.oh-my-zsh/custom/plugins
 - clone powerlevel10k to ~/.oh-my-zsh/custom/themes
Install neovim
Install keyd and run keymaping script from .local/scripts
